¿Qué hace esta sincronización?
  • Consulta football-data.org buscando los equipos del Mundial 2026 (/competitions/WC/teams?season=2026).
  • Empareja por código TLA (3 letras) → nombre corto → búsqueda parcial.
  • Guarda el api_football_id en cada equipo que encuentre.
  • Una vez sincronizados, aparecerá el botón Stats en los partidos de la Polla para ver H2H y forma reciente.
  • La API tiene caché de 6 horas por partido para no agotar el plan gratuito.
